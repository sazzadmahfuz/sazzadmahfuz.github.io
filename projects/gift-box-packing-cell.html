Gift Box Packing Cell

A Dobot M1 Pro SCARA, two conveyor belts and a USB camera that pack Christmas gift boxes: one card and two candies go into each box, then the lid. Built by a team of three in Applied Robotics Project II at HAMK, Robotics Laboratory B118.

03 — How it works

System overview

USB cameraabove both belts
→
YOLO11ncard, candy, box, lid
→
Homographypixel → robot X/Y, 0.92 mm
→
cell_livestate machine, safety gate, log
→
Dobot M1 ProTCP 29999 / 30003
→
DO1–2 vacuum · DO3/4/16 beltTB6600 stepper driver
  1. The box belt brings an open box until an E18-D80NK sensor stops it. It runs on its own Arduino UNO R4 WiFi.
  2. The camera checks that the box is standing still at the taught box slot.
  3. The robot starts the object belt with its digital outputs. It stops when the items the box still needs are in the pick area.
  4. The robot moves out of view. YOLO finds the card and candies, and the homography turns pixels into robot coordinates.
  5. The robot picks each item with the vacuum cup, turns it to the box angle and places it, then puts the lid on.
  6. An operator takes the closed box away and the next box comes in.

Safety gate. Before the robot can move, the software checks a speed cap, the teacher’s approval (name and date), taught points within reach, calibration, vision model, output wiring, an operator at the e-stop, and the J1 range for the path home. Passing the gate issues a one-time arm token that is used up by that single run.

Operator console. A browser console at 127.0.0.1:8765 shows device checks, the live camera with detections, the cycle state and the run logs.

Simulation first. The same cycle runs offline with simulated devices or in a RoboDK station of the cell, so the logic was tested before the robot moved.

04 — Machine vision

Detection and calibration

YOLO11n trained on 147 lab images and validated on 22, four classes: card, candy, box and lid. Pixel positions are mapped to robot X/Y with a homography fitted on five calibration marks that the robot touched. When the camera turned 6.3° in its holder, a view correction re-fitted the calibration without recalibrating.

06 — Engineering

Problems found on the real cell

J1 joint limit

The first pick faulted: a straight move from home needed J1 at about 90°, the M1 Pro allows ±85° (controller alarm 23).

fix: route home → above box slot → item

Box slot off by 78 mm

Items were placed beside the box. The taught slot did not match the box position.

fix: slot taught again, camera confirms the box

Camera moved 6.3°

The camera rotated in its holder between sessions, so pixel-to-robot mapping drifted.

fix: view correction re-fits the calibration

Lid step

Some runs paused near the 375 mm reach limit and the lid does not always close fully.

status: open, next on the list
